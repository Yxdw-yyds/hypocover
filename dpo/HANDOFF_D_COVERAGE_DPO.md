> **分支**：`d-coverage-dpo`（基于冻结交接根提交 `85804b1`）  
> **任务**：HypoSpace 3D 体素结构假设生成（84 train / 12 validation / 24 test 冻结划分）  
> **基座模型**：`Qwen/Qwen2.5-1.5B-Instruct`（仅 **1.5B 参数**，本地单卡 `RTX 4070 Ti SUPER` 16GB 训练与推理，**API 费用 \$0.00**）  
> **评测协议**：**100% 原生官方协议**——未改一字的官方提示词 `Benchmark3D.create_prompt`、官方逐层体素输出格式 `Structure:\nLayer 1:...`、每槽位单次生成（$m=1$，预算 $N=|H_O|$）、生成端无真值校验器（`no-validator`）、官方 `score_predictions.py` 评分。

## 1. 一句话核心结论

在 **不改输出表示**（不使用 B 的手工高度向量双射）且 **突破黑盒提示词包装无信号瓶颈**（回应 C 的负结果与探针 1–3）的前提下，我们通过**参数空间梯度学习**将一个 **0.00% 恢复率**的 `1.5B` 开源小模型提升至：
- **严格冻结解码参数（`T=0.7, top_p=0.8`）下**：测试集 **VR = 100.00%**（1,296 次生成 **0 次非法、0 次截断**，平均仅 **61.3 tokens**）、**RR = 60.24% ± 0.76%**（超越 `DeepSeek-V4-Flash` 512-token 基线 `53.55%` **+6.69 个百分点**，在更难的三列题 $k=3$ 上从 `44.14%` 跃升至 **`59.36%`，+15.22 个百分点**）；
- **消除前缀树核采样截断偏置（`T=1.0, top_p=1.0` 无偏祖先采样）后**：测试集 **VR = 99.85%**、**RR = 64.04% ± 0.77%**，对 `Base`、`Validity-SFT`、`History-SFT`、`Imbalanced-DPO` 及 `DeepSeek-512` 的逐题配对 95% Bootstrap 置信区间**全部严格大于 0**（较 `DeepSeek-512` **+10.49 pp, 95% CI [+3.50, +17.03]**；较同题 `Qwen3-8B` 的 `1.08%` 提升 **+62.96 pp**，而参数量仅为其 **1/5.3**）。

同时，本实验揭示了两个具有独立方法论价值的机器学习发现：
1. **DPO 边际捷径与熵坍缩（Prior-Shortcut Entropy Collapse）**：若在覆盖率偏好对中引入复杂度偏置加权（`dpo_imbalanced`），DPO 会利用正负样本边际分布不对称走捷径，将策略熵坍缩到单一全满三层模式（`NR` 跌至 `13.9%`，测试集 `RR` 暴跌至 `12.86%`）；我们提出的**边际分布对称化（Symmetric Marginal Matching）+ NLL 锚定正则（Anchored DPO）**彻底消除了该坍缩。
2. **变长前缀树核采样饥饿定理（Prefix-Tree Nucleus Starvation）**：官方体素格式省略顶层全零层，导致 1 层结构（如 $H=(1,1,1)$）在 `Layer 1` 结束处的 `<EOS>` 先验分支概率仅为 $1/27 \approx 3.7\% < 1 - \text{top\_p} = 20\%$，被标准 `top_p=0.8` 核采样确定性截断为 0。切换为校准策略上的无偏祖先采样（`T=1.0, top_p=1.0`）直接带来显著额外覆盖增益。

## 3. 方法设计（严格防泄漏，仅读取 84 道 `train` 题）

### 3.1 严格数据隔离证明
- 在 $3\times 3$ 网格上，两列俯视图共 $\binom{9}{2}=36$ 种（18 train / 6 val / 12 test），三列俯视图共 $\binom{9}{3}=84$ 种（66 train / 6 val / 12 test）。
- **验证集与测试集的每一道俯视图空间坐标组合在训练集中均从未出现过**（由单元测试 `dpo/test_dpo.py::test_disjoint_splits_and_observations` 严格校验，且 `load_train_questions_with_gt` 对非 `train` 集设有硬断言拦截）。因此测试集上 **100% VR** 是纯粹的跨空间位置泛化，绝无背题可能。

### 3.2 四阶递进训练与消融设计
所有微调模型采用完全相同的基座 `Qwen/Qwen2.5-1.5B-Instruct` 与 LoRA 配置（`r=32, lora_alpha=64`，作用于全部注意力与 MLP 投影层，可训练参数 36.9M / 2.34%），且**仅对回答部分的体素 token 计算损失**（Prompt 部分 `labels = -100`）：

1. **`Validity-SFT`（无记忆合法性基线）**：在训练题前缀状态 $(O, H_{<t})$ 上，目标 $y$ 从全部合法解 $H_O$ 中**忽略历史**均匀采样。用于隔离“仅学物理合法性（俯视一致 + 重力支撑）、不学历史排斥”的独立贡献。
2. **`History-SFT`（历史条件最大似然基线）**：在与 `Validity-SFT` 完全配对的输入前缀 $(O, H_{<t})$ 上，目标 $y^+$ 从**未发现合法解集合 $H_O \setminus H_{<t}$** 中采样。
3. **`Imbalanced-DPO`（朴素复杂度加权 DPO 负对照）**：以 `History-SFT` 为参考模型 $\pi_{\text{ref}}$，对高复杂度未发现解赋予 1.35 倍偏好权重并在简单优先前缀上构造负样本，用于验证非对称边际分布引发的 DPO 熵坍缩。
4. **`Symmetric Anchored Coverage-DPO`（本文主方法）**：
   - **在策略碰撞挖掘 + 边际对称构造**：融合 `History-SFT` 在训练题上的真实重复碰撞轨迹（`onpolicy_dup`）与均匀随机排列前缀下的最近邻 3D 汉明距离碰撞负样本 $y^- = \arg\min_{h \in H_{<t}} \|y^+ - h\|_1$。由于前缀来自 $H_O$ 的均匀随机排列，任意 $h \in H_O$ 作为正样本 $y^+$ 与负样本 $y^-$ 的先验边际概率严格相等（$\bar{p}(y^+) \equiv \bar{p}(y^-) = 1/|H_O|$），**彻底封死不看上下文历史的捷径解**。
   - **锚定覆盖率偏好目标**：
     $$\mathcal{L}_{\text{Cov-DPO}}(\theta) = -w \log \sigma\!\left(\beta \left[\log \frac{\pi_\theta(y^+\mid O, H_{<t})}{\pi_{\text{ref}}(y^+\mid O, H_{<t})} - \log \frac{\pi_\theta(y^-\mid O, H_{<t})}{\pi_{\text{ref}}(y^-\mid O, H_{<t})}\right]\right) - \alpha \frac{\log \pi_\theta(y^+\mid O, H_{<t})}{|y^+|}$$
     其中 $\beta=0.35, \alpha=2.0, \text{lr}=2\times 10^{-5}$。DPO 项中 $y^+$ 与 $y^-$ 共享相同的格式前缀 token，梯度精确聚焦于二者发生分歧的 1~3 个体素决策位；NLL 锚定项则锁定物理合法流形（训练全程 `NLL ≈ 0.058` 不漂移）。

## 5. 深入机制分析与诚实局限讨论（建议放入视频最后 1.5 分钟）

1. **为什么 `1.5B` 微调模型零草稿就能达到 `99.85%~100%` 物理合法率？**
   - 基座 `Qwen2.5-1.5B` 解析率已达 `100%`，但会照搬提示词中的四角示例并频繁产生悬空方块（`VR = 0.0%`）；`DeepSeek-Flash` 在 C 的探针 1（`fixed_brief`）中一旦被禁止写推理草稿，不合法率也飙升到 `48.6%`。
   - 参数微调将“俯视图投影一致 + 逐层重力支撑”直接编译进了前馈与注意力权重中，无需任何推理草稿即可在未见测试俯视图上实现零违规、零截断（平均仅 ~60 tokens，推理吞吐提升约 5 倍）。
2. **为什么无草稿（Zero-CoT）逐层体素生成的覆盖率渐近收敛在 `~64%`（赠券收集上界）附近？（诚实归因）**
   - 均匀无记忆独立合法采样在 $k=2$（9 解）和 $k=3$（27 解）上的理论期望恢复率恰好为 $\frac{1}{2}[(1-(8/9)^9) + (1-(26/27)^{27})] = \mathbf{64.63\%}$。
   - 在验证集无偏采样（`T=1.0, top_p=1.0`）对照下，`Validity-SFT`（`61.93%`）、`History-SFT`（`61.11%`）与 `Coverage-DPO`（验证 `59.57%`、测试 **`64.04%`**）共同逼近但均未突破 `64.63%` 上界。这说明：
     1. 在标准低温核采样（`T=0.7, top_p=0.8`）下，`History-SFT` 与 `Coverage-DPO` 相对 `Validity-SFT` 的大幅提升（测试集 `46.40% → 60.24%`）主要来自**对输出层数分布的去偏校准**（抑制了低温下向 3 层高结构的过度集中），配合无偏祖先采样（`64.04%`）彻底消除了矮层分支饥饿；
     2. 但在**零中间推理草稿（Zero-Scratchpad，仅 ~57 tokens）**约束下，`1.5B` 模型的单次前向传播并不足以在第 20~27 轮对 20+ 个三维矩阵完成精确的无放回集合求补。要突破 `64.63%` 的无记忆天花板，必须结合紧凑状态表示（如模块 B 达 `100%`）或显式推理草稿算力（如模块 C 的 1024-token 基线达 `76.39%`）。这一点从参数空间视角将 B、C、D 三条实验线严密统一。

## 6. 仓库产物与复现命令

### 6.1 目录结构
- `dpo/common.py`：严格数据集加载器（含测试/验证真值硬隔离断言）、体素规范化与特征计算
- `dpo/build_data.py`：构造配对 `sft_validity`、`sft_history` 与边际对称 `dpo_coverage` 数据集
- `dpo/train_sft.py`：显存优化版仅回答位置 `lm_head` 交叉熵 LoRA SFT 训练器
- `dpo/train_dpo.py`：精确参考似然预计算 + 对称锚定 `Coverage-DPO` 训练器
- `dpo/evaluate.py`：严格遵循官方 `Benchmark3D.create_prompt` 与 `score_predictions.py` 的批量 GPU 评测器
- `dpo/analyze.py` & `dpo/make_plots.py`：配对 Bootstrap 置信区间统计与发表级 `RR@k` SVG/CSV 曲线生成
- `dpo/results_summary.json`：完整验证集与测试集统计指标与置信区间 JSON
- `dpo/figures/`：`rr_curve_{validation,test}_k{2,3}.{svg,csv}`（可直接拖入 PPT / 视频剪辑）
- `dpo/runs/{validation,test}/<arm>/rep{1,2,3}/{predictions.jsonl,score.json,traces/}`：全部官方评分文件与逐槽位轨迹
