# 历史排序小实验（2026-11-25）

从训练集既有轨迹中，两列和三列各取两个满足条件的问题。历史已过半程，至少包含三个不同结构，且重复最多的结构原本不在末尾，仍有标准解未出现。两组共享同一题目和历史，只把该结构移到末尾一次。并列时取最早出现者。使用官方逐层提示和解析器，DeepSeek 官方 deepseek-flash，关闭思考，temperature 0.7，top_p 0.8，每次最多输出 1024 tokens。每题每组只采样一次。

共 8 次调用，输入 9712 tokens，输出 4787 tokens。新解按“属于该题标准解且此前未出现”计。原顺序 2/4，重排 4/4，均为单步命中数。两次差异都来自原顺序输出截断。样本很小，未证明减少重复或提高整题覆盖率，也未训练排序器。结论为停止此方向，不扩跑。

在项目根目录运行 `python -B -m c4.order_probe` 可离线重建四组对照。随附的历史快照只含解析后的结构，null 表示当次无法解析。显式添加 `--live` 会重新调用 API 并产生费用，随机输出可能不同。
